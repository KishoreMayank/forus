Treatment follow-up · three directions

Static sketches for the clinic’s front desk. Each one answers the same three questions: where these patients come from, what the tool is connected to, and what is happening right now. Numbered markers link each element to the reason it’s there.

A · List. One quiet table, grouped by what’s happening. Best for a front desk that checks in a few times a day and wants the whole picture on one screen.

  1. 1One sync line, always visible. Staff only need to know the data is current. It turns amber if a sync fails, and that’s the only time it should catch the eye. Clicking it opens Connections.
  2. 2Where the patients come from. A plain sentence answers “why is this person on my list?” before anyone asks. Nobody adds patients by hand; they come from the charts.
  3. 3The only thing addressed to a person. Clinical questions are the one case where the tool hands off to a human. They sit above the list, named for the dentist they’re for.
  4. 4Grouped by state, not tabs or filters. With a few dozen patients, everything fits on one scroll. Tabs would hide two-thirds of the picture.
  5. 5The chart line. Tooth, procedure code, dentist and date, written the way the practice software shows them. Every row traces back to a real treatment-plan entry.
  6. 6“Next” is the only coloured column. It answers the question staff actually have: what happens without me, and when. There are no approve buttons, because nothing waits on approval.
  7. 7History opens in place. The dentist’s exact words, then a short dated log tagged by where each step happened (chart or text). You never leave the list.
  8. 8A visit isn’t the finish line. A case only closes when the chart says the crown is seated. That stops attended-but-unfinished treatment from dropping off.

  2. 2Amber means a person is involved. Only one colour besides teal, used only when someone at the practice, here a dentist, is part of the next step.
